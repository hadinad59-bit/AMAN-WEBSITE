# أمان (Aman)

موقع توعوي تعليمي للأمن والسلامة — عربي/إنجليزي، بدون تسجيل أو حفظ بيانات شخصية.

موقع ثابت (HTML/CSS/JS) بدون خادم أو قاعدة بيانات.

## التشغيل محليًا
افتح `index.html` مباشرة بالمتصفح، أو شغّل خادمًا ثابتًا بسيطًا:

```
python -m http.server 8420
```

ثم افتح `http://localhost:8420`.
